# Practical Assignment 4: Classification Models (Breast Cancer Dataset)

## Overview
Comparative performance evaluation of four supervised machine learning classification algorithms—**Support Vector Machine (SVM)**, **Decision Tree**, **K-Nearest Neighbors (KNN)**, and **Gaussian Naïve Bayes**—implemented in Python using the **Breast Cancer Wisconsin (Diagnostic) Dataset**.

## Project Structure
- `breast_cancer_classification.py`: Main Python script for data loading, preprocessing, model training, evaluation, and visualization.
- `breast_cancer_dataset.csv`: Exported dataset (569 samples, 30 features, 2 classes: malignant & benign).
- `breast_cancer_model_comparison.csv`: Generated performance metrics table.
- `sample_output.txt`: Console execution output.
- `requirements.txt`: Required Python dependencies.
- `screenshots/`: Generated comparison plots and confusion matrices.

## How to Run
```bash
pip install -r requirements.txt
python breast_cancer_classification.py
```
